Note: How to display the logo in Overleaf

To display the logo correctly in your resume:

  1. Download the NIT Warangal logo using the button below.
  2. Upload this image to your Overleaf project using the Upload button in the left file panel.
  3. Ensure the uploaded file is named logo.png — it must match the LaTeX code exactly.

This line is already in the generated LaTeX:

\includegraphics[width=2.35cm]{logo.png}

After uploading and compiling, the logo will appear correctly in your resume.
